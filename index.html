LKPD: Manajemen Server VPS AWS

Fase 1: Pengenalan Konsep VPS & Cloud
Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.
Shared Hosting

Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna (website). Sumber daya seperti CPU, RAM, dan penyimpanan dibagi bersama, sehingga harganya murah namun performa dapat saling memengaruhi jika ada website lain yang trafiknya tinggi.

Dedicated Server

Layanan di mana pengguna menyewa satu server fisik secara penuh tanpa dibagi dengan pengguna lain. Menawarkan performa maksimal, kontrol penuh, dan keamanan tingkat tinggi, namun biayanya jauh lebih mahal dan membutuhkan keahlian teknis tinggi untuk mengelolanya.

Amazon Lightsail

Layanan Virtual Private Server (VPS) dari AWS yang dirancang agar lebih mudah, sederhana, dan ramah pemula dengan harga tetap (flat-rate). Sangat cocok untuk proyek berskala kecil hingga menengah, web development, atau aplikasi mandiri.

Amazon EC2

Layanan komputasi awan (cloud computing) tingkat lanjut dan fleksibel dari AWS yang menyediakan kapasitas komputasi resizable (bisa diubah sesuai kebutuhan) di cloud. Pengguna memiliki kontrol penuh atas infrastruktur virtual dan sistem operasinya, ideal untuk aplikasi enterprise skala besar.
